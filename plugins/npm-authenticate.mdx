---
title: "NpmAuthenticate@v1"
description: "Authenticate private npm feeds in Docker builds."
---

Use this plugin to authenticate registries in your project's `.npmrc`. It exposes
the authenticated configuration as a BuildKit secret named `npmrc` and leaves
your source file unchanged.

## Usage

Add your feed URLs to `.npmrc`, then enable the plugin in `build.yml`:

```yaml
plugins:
  - NpmAuthenticate@v1
```

Run `buildcharts generate` before `docker buildx bake`. Mount the secret when
installing packages:

```dockerfile
WORKDIR /app
COPY package.json package-lock.json ./
RUN --mount=type=secret,id=npmrc,target=/app/.npmrc,required=true \
    npm ci
```

The npm charts already mount this secret for pnpm.

## What it does

- Reads default and scoped registries from `.npmrc`.
- Prefers matching npm service connections, then job tokens, then existing credentials.
- Uses the Azure Artifacts Credential Provider for local sign-in when Azure DevOps Services feed credentials are missing.
- Writes `.buildcharts/secrets/npmrc` and adds it to the generated Bake secrets.

## Environment variables

| Variable | Description |
| --- | --- |
| `NPM_AUTHENTICATE_WORKING_FILE` | Source configuration file. Defaults to `.npmrc` in the current directory. |
| `NPM_AUTHENTICATE_HELPER_VERSION` | Exact credential provider release, such as `1.4.1`. Unset or empty selects latest. |
| `NPM_AUTHENTICATE_CUSTOM_ENDPOINTS` | Comma-separated npm service connection IDs. |

In Azure Pipelines, pass these environment variables to the step running BuildCharts:

```yaml
env:
  SYSTEM_ACCESSTOKEN: $(System.AccessToken)
  SYSTEM_TEAMFOUNDATIONCOLLECTIONURI: $(System.TeamFoundationCollectionUri)
  SYSTEM_SERVERTYPE: $(System.ServerType)
```

The job identity needs feed access. `ARTIFACTS_CREDENTIALPROVIDER_ACCESSTOKEN`
is also accepted when `SYSTEM_ACCESSTOKEN` is empty.

For selected service connections, supply `ENDPOINT_URL_<ID>` and
`ENDPOINT_AUTH_<ID>` with Azure agent authorization JSON. Supported schemes are
`Token` with `apitoken`, and `UsernamePassword` with `username` and `password`.
Uppercase IDs and replace spaces and periods with underscores. Selecting an ID
does not retrieve credentials or grant feed access.

## Notes

- Exclude `.npmrc` and `.buildcharts` from the Docker build context. Keep the generated secret until Bake finishes and exclude it from published artifacts.
- Local sign-in runs through `dotnet` on Windows, Linux, and macOS and may open a browser or show a device code. CI disables interactive sign-in and fails when Azure feed credentials are missing. Azure DevOps Server requires supplied credentials.
- Provider versions use separate folders under `.buildcharts/plugins/NpmAuthenticate@v1`. Existing installations are reused until generation clears `.buildcharts`. NuGet has a separate `NUGET_AUTHENTICATE_HELPER_VERSION` override.
